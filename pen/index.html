STEP 03 — 产品原理

三节点工作流，让纸笔接入数据世界

不改变纸笔习惯，不增加师生负担，让每一次批改都成为学情数据。

📄
NODE 01
点阵码纸面
普通纸张印制隐形点阵码，肉眼不可见但设备可精准识别。书写即定位，落笔即采集。
✏️
NODE 02
智能手写笔
笔尖内置高速摄像头，实时捕捉点阵位置与书写轨迹，批改过程动态上传云端。
☁️
NODE 03
云平台分析
数据即时汇聚分析，生成错题本、学情统计与教学建议，驱动精准施教与科学决策。
点阵码 + 智能手写笔 = 传统纸笔接入 数据世界

教师用智慧笔在纸质作业和试卷上正常批改。笔尖划过纸面的瞬间，对错标记、批注轨迹、批改时间、知识点关联被动态采集，数据流从纸面升腾，进入班级学情池。

  • 对错标记自动识别，批改结果即时数字化
  • 批注笔迹完整留存，支持回溯与共享
  • 知识点自动关联，错题标签精准打标
  • 批改效率量化，班级学情自动汇聚
